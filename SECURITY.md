# Sicherheitsmeldungen

Bitte keine Zugangsdaten, persönlichen Daten oder Schritte zum Ausnutzen
einer Sicherheitslücke in einem öffentlichen Issue posten. Nutze nach
Möglichkeit die private GitHub-Sicherheitsmeldung im Tab **Security**.
Falls diese nicht verfügbar ist, bitte in einem Issue ohne technische Details
um einen privaten Kontaktweg.
